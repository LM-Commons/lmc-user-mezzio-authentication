This components provides adapters for the Mezzio Authentication middleware
based on Laminas Authentication

## Requirements

- PHP 8.2 or higher

## Installation

You can install the LMC User Authentication for Mezzio library with composer:

```sh
$ php composer.phar require lm-commons/lmc-user-mezzio-authentication
```
