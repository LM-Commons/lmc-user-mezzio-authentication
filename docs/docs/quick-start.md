## Requirements

- PHP 8.3 or higher

## Installation

Lmc User Mezzio Authentication only officially supports installation through Composer.

Install the module:

```sh
$ composer require lm-commons/lmc-user-mezzio-authentication
```

You will be prompted by the Laminas Component Installer plugin to inject the
component into your `config/config.php` file.
